A LITTLE SPACE ABOUT ME — MANASA M

FILES
- index.html: Complete personal blog website (HTML, CSS and JavaScript in one file).

HOW TO OPEN
1. Extract the ZIP file.
2. Open the extracted folder.
3. Double-click index.html, or open it with Chrome/another modern browser.
4. The website works locally and does not need an internet connection.

HOW TO CUSTOMIZE
- Open index.html in a text editor (Notepad, VS Code, etc.).
- Update the About Me and other section text.
- In the Gallery section, replace the note with your own photos. You can add images in an "images" folder and use <img src="images/your-photo.jpg" alt="Description">.
- Add your own email or social profile link in the Contact section if you want to share it publicly.
- Personality details were left general because no personality description was provided.

PUBLISHING
You can publish the folder using a static website host such as GitHub Pages or Netlify. Review the content and remove private information before making it public.
